# Реальные значимые промпты

## 20 ноября 2026 — исходное задание пользователя

> Начни разработку frontend приложения «Analyst Days: моя программа».
> Прочитай README.md, docs/context-v0.md и docs/frontend-spec.md.
> Используй эти документы как требования к реализации.
> Сначала проверь структуру проекта и состояние Git. Сохрани чужие изменения.
> Работай только в этом frontend-репозитории, backend не меняй.
> Реализуй MVP по ТЗ и подключение к отдельному backend через API-клиент.
> Соблюдай согласованный API-контракт из документов.
> Не останавливайся на плане или статическом макете: реализуй экраны,
> навигацию, выбор докладов, личную программу, отображение конфликтов,
> состояния загрузки и ошибок, адаптивную верстку.
> Установи зависимости, проверь сборку и типы, запусти приложение
> и проверь основные сценарии в браузере, если инструмент доступен.
> Если backend ещё недоступен, явно отметь, что интеграция не проверена.
> Обнови README инструкциями по установке, настройке API и запуску.
> При неоднозначностях принимай разумные решения в рамках ТЗ.
> API-контракт самостоятельно не меняй.
> Сделай коммит результата. Пока не пушь и не разворачивай приложение.
> В конце укажи, что реализовано, что проверено и какие ограничения остались.

Других пользовательских промптов для этой реализации не было. История не дополнена вымышленными итерациями.

## Уточнение границ проверки

> проверяй только фронт. полное тестирование потом отдельно буду проверять

После этого уточнения проверка реального backend прекращена; итоговая проверка ограничена frontend и явными API-фикстурами в Playwright. Полная интеграция не объявлена проверенной.
