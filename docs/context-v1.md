# Контекст v1 — фактическая frontend-реализация

Дата: 20 ноября 2026. Исходные `context-v0.md` и `frontend-spec.md` сохранены без изменений.

## Что реализовано

- Next.js App Router, TypeScript, Tailwind CSS; точные версии зависимостей и npm lock-файл.
- Главная, программа и личная программа, общая навигация со счётчиком.
- Два дня и залы из Conference; отмена старых запросов при смене фильтра.
- Карточки, подробности с описанием и bio, доступный модальный диалог.
- Единое состояние личной программы, пессимистический выбор, блокировка параллельных изменений.
- Единственный первоначальный GET /me/program, в том числе при Strict Mode.
- PUT обновляет программу из ответа; DELETE сопровождается GET. При неопределённом результате выполняется синхронизация; при её провале изменения заблокированы до повтора.
- Конфликты и счётчики исключительно из backend; frontend связывает ID с выбранными Talk. Сохранение с конфликтом не блокируется.
- Ошибки, загрузка, повторы, пустые фильтры и пустой день. Время в Europe/Moscow; условные даты не выдаются за даты конференции.
- Same-origin rewrite, серверный BACKEND_URL, передача cookie средствами proxy. Нет API routes с бизнес-логикой, локальной БД, localStorage или неявных моков.
- Адаптивная вёрстка, видимый фокус, aria-live, Escape и возврат фокуса.
- Dockerfile для будущего размещения и обновлённый README.

## Принятые решения

- Нативный `<dialog>` с дополнительным циклическим переключением фокуса по Tab/Shift+Tab.
- Стили без внешних шрифтов, официальных логотипов и сторонних изображений.
- Фикстуры из 20 вымышленных докладов находятся только в `tests/fixtures.ts`. Все их условные даты централизованы там. В приложении используются исключительно данные API.
- Выбор дня/зала не сохраняется между переходами: начальное состояние соответствует ТЗ (первый день, все залы).
- Автоматически созданный Next.js файл `AGENTS.md` включён в репозиторий.

## Границы проверки

По уточнению пользователя проверяется только frontend. Полный интеграционный прогон перенесён на отдельный этап. До уточнения выполнены GET health/conference/talks реального backend: контракт и 20 докладов наблюдались. При попытке сквозного сценария backend уже не принимал соединения; сценарий не завершён и не считается пройденным.

Реальная передача Cookie/Set-Cookie, серверная идемпотентность, изоляция, БД и сохранение после перезапуска backend остаются на отдельную интеграционную проверку. Код backend не изменялся. Docker и публикация не проверялись. Показатель «три доклада и конфликт за две минуты» остаётся гипотезой, пользовательское исследование не проводилось.

Результаты frontend-проверок: [UI-отчёт](ui-checks.md). Команды: [README](../README.md).
