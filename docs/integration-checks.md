# Совместная проверка — 20 ноября 2026

Проверялись два локальных репозитория с чистым исходным Git-состоянием. Рабочая БД не изменялась: использована отдельная SQLite `/private/tmp/analyst-days-integration.db` с демонстрационным seed. Общий context-v0 побайтно одинаков.

## Результаты

- Backend: `python -m pytest -q` — 37 passed; `python -m pip check` — зависимости согласованы. Есть предупреждение Starlette о deprecated httpx в TestClient.
- Frontend: `npm run build`, `npm run typecheck`, `npm run lint` — успешно.
- `REAL_API=1 npm run test:e2e` — 11 passed (8.4 s): 10 тестов с явными фикстурами и один сквозной тест с реальным API.
- Реальный сквозной тест: просмотр и подробности, добавление двух пересекающихся докладов, счётчики и симметричные конфликты, удаление с исчезновением конфликта, reload с сохранением выбора, идемпотентный PUT, доклады встык, пустая программа нового браузерного контекста.
- Проверены Cookie/Set-Cookie через Next.js proxy, HttpOnly, SameSite=Lax, Path=/ и Cache-Control: no-store.
- Дополнительный локальный Playwright-прогон production-сервера: реальная остановка и повторный запуск uvicorn с той же БД сохраняют выбор в прежнем браузерном контексте.
- Реальное отключение backend показывает ошибки и кнопки повтора; после запуска backend повторная загрузка и синхронизация восстанавливают работу.
- Через proxy проверены 404 TALK_NOT_FOUND, 422 VALIDATION_ERROR и 403 ORIGIN_NOT_ALLOWED для чужого Origin.
- Все три страницы с реальными данными проверены на 360, 768 и 1440 px: горизонтального переполнения нет. Просмотрены скриншоты программы 360 px и личной программы 1440 px; наложений и обрезанного текста не обнаружено.
- Клавиатура, focus trap, Escape, возврат фокуса, фильтры, быстрые клики и неудачная синхронизация покрыты UI-тестами с фикстурами. В дополнительном production-прогоне ошибок JavaScript не было.

## Исправления

Frontend: npm start использовал next start при output: standalone и выдавал предупреждение Next.js. Теперь scripts/start.mjs копирует public и .next/static в standalone и запускает сгенерированный server.js. Исправленный сервер прошёл дополнительный production-прогон; линтер после изменения успешен.

Обновлены README: ссылки на соседние репозитории и актуальный статус интеграции. Прикладной код backend менять не потребовалось. API-контракт не изменялся.
